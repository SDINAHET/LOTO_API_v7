Loto Tracker
Projet Technologies Architecture Timeline

Application Full Stack RNCP6

Loto Tracker est une application web moderne permettant de gérer des tickets Loto, consulter automatiquement les tirages FDJ, calculer les gains et suivre les statistiques des joueurs en temps réel grâce à une architecture Full Stack sécurisée.

Spring Boot Java PostgreSQL MongoDB PWA Android Prometheus Grafana Uptime Kuma
📱 Application installable détectée — ajoute Loto Tracker à ton écran d’accueil Android.

Fonctionnalités principales

  • Authentification JWT sécurisée
  • Gestion complète des tickets
  • Calcul automatique des gains
  • Historique FDJ depuis 2019
  • API REST Spring Boot
  • Frontend responsive HTML/CSS/JavaScript
  • PWA installable Android
  • Monitoring Grafana + Prometheus
  • Supervision Uptime Kuma

Technologies utilisées

Le projet repose sur une architecture moderne orientée Full Stack, API REST et supervision serveur.

Backend

Java 21, Spring Boot 3, Spring Security, JWT, API REST sécurisée.

Frontend

HTML5, CSS3, JavaScript responsive, interface Glassmorphism moderne.

Base SQL

PostgreSQL pour les utilisateurs, tickets, gains et authentification.

Base NoSQL

MongoDB pour l’historique des tirages et les statistiques volumineuses.

Monitoring

Prometheus, Grafana et Uptime Kuma pour la supervision temps réel.

PWA Android

Installation directe depuis Chrome mobile sans passer par le Play Store.

Architecture réseau

Le projet est hébergé derrière Apache Reverse Proxy avec HTTPS Let's Encrypt.

🌐 Frontend

HTML / CSS / JavaScript responsive hébergé via Apache HTTPS.

⚙️ Backend API

Spring Boot REST API sur serveur Linux sécurisé.

🗄 PostgreSQL

Stockage relationnel : utilisateurs, tickets, gains.

📊 MongoDB

Historique FDJ, statistiques, volumes importants de données.

📈 Monitoring

Grafana, Prometheus, Uptime Kuma.

🔒 Sécurité

HTTPS, JWT, Spring Security, CORS sécurisé.
